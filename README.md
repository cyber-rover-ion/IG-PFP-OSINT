# IG-PFP-OSINT

A small research utility for retrieving a public Instagram profile-picture URL from publicly available profile-page data.

## Overview

IG-PFP-OSINT explores how publicly exposed web data can be collected and interpreted for legitimate research and learning. It is designed around public profile information and does not require Instagram login credentials.

## Capabilities

- Retrieve publicly accessible profile-picture information
- Work with public profile-page data
- Use standard HTTP requests
- Avoid requiring authenticated Instagram API access
- Provide a compact foundation for OSINT/web-data experiments

## Responsible Use

Use this project only with information that is publicly accessible and in ways permitted by the relevant service policies.

Do not use it to:
- Access private accounts
- Bypass authentication or access controls
- Collect private or restricted information
- Harass, track, or target individuals

## Project Scope

This project is a learning and research utility. Public availability of information does not remove the responsibility to use it lawfully and respectfully.

## Development

The implementation is intentionally small so the public-data retrieval workflow remains easy to understand and extend.
